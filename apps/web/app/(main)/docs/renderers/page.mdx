# Renderers

This repository currently focuses on web UI and HTML email generation.

All renderers share the same workflow:

1. Define a catalog with `defineCatalog`
2. AI generates a JSON spec
3. The renderer turns the spec into platform-native output

## React

Render specs as React component trees in the browser. Supports data binding, streaming, actions, validation, visibility, and computed values.

```tsx
import { defineRegistry, Renderer } from "@json-render/react";
import { schema } from "@json-render/react/schema";

const { registry } = defineRegistry(catalog, { components });
<Renderer spec={spec} registry={registry} />
```

See the [@json-render/react API reference](/docs/api/react) for details.

## React Email

Generate production-ready HTML emails from JSON specs.

```tsx
import { createRenderer, standardComponents } from "@json-render/react-email";

const renderEmail = createRenderer({
  components: standardComponents,
});

const html = await renderEmail(spec);
```

See the [@json-render/react-email API reference](/docs/api/react-email) for details.
